# Block Quest: Classroom Edition

Weekly spelling words and Bible memory verse games for a 2nd-grade classroom.

Play: **https://bsisco-star.github.io/block-quest-classroom/**
Teacher guide: **https://bsisco-star.github.io/block-quest-classroom/teacher-guide.html**

Progress is saved in the browser on the computer where it's played (localStorage). Use Teacher Tools > Backup to save a copy.
